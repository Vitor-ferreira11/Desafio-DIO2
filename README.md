# Calculadora de partidas ranqueadas

Exercício JavaScript que calcula o saldo de vitórias menos derrotas e apresenta o nível do herói.

Com Node.js 22 ou superior, execute `node index.js`. Execute `node --test` para verificar limites e entradas inválidas. Vitórias e derrotas devem ser inteiros não negativos.

## Regra preservada do projeto

A implementação classifica **pela quantidade de vitórias**, enquanto o saldo exibido subtrai derrotas. Faixas: Ferro abaixo de 10; Bronze de 10 a 20; Prata de 21 a 50; Ouro de 51 a 80; Diamante de 81 a 90; Lendário de 91 a 100; Imortal acima de 100.

Essa regra foi preservada durante a correção de entradas. Alterá-la para usar saldo ou mudar fronteiras requer confrontar o enunciado original, que não está no repositório.
